## About This Laboratory

This website contains the practical work completed as part of the Cloud Infrastructure Laboratory. The experiments cover virtualization, containerization, infrastructure automation, continuous integration, code-quality analysis, container orchestration, Docker Swarm, and Kubernetes.

The laboratory work was performed using tools such as Vagrant, Docker, Docker Compose, Jenkins, Chef, Ansible, SonarQube, Docker Swarm, and Kubernetes.

## Learning Outcomes

After completing these experiments, I was able to:

1. Create and manage virtual machines.
2. Build, run and manage Docker containers.
3. Create custom Docker images using Dockerfiles.
4. use persistent storage, networks and environment variables in containers.
5. Deploy multi-container applications using Docker Compose.
6. understand continuous integration using Jenkins.
7. automate server configuration using Chef and Ansible.
8. analyse source-code quality using SonarQube.
9. deploy and scale services using Docker Swarm.
10. deploy, expose, scale and test self-healing applications using Kubernetes.
